# Creator AI Studio — Android starter

This is a buildable Android starter app project.

Included:
- Android app interface
- Multi-image picker
- Voiceover audio picker
- 9:16 / 16:9 format selector
- GitHub Actions workflow to build a debug APK

Important: this starter does not yet render MP4 video or provide speech recognition, semantic AI scene matching, subtitles, transitions, or professional effects. Those are separate development tasks and are not falsely presented as completed.

After uploading the project files to the repository, open Actions and run **Build Android APK**. Download the `Creator-AI-Studio-debug-apk` artifact.
